The flight plan

First match
wins

The service worker’s logic is one fixed file. Only its configuration is generated: an ordered list of rules you can read.

  • Pages network first, with a stored copy if the network is slow
  • Images and assets stale while revalidate
  • The control panel and /actions/ never cached
  • Separate limits for pages, assets and images, and a real expiry

Lite runs these defaults. Pro lets you write your own rules.

The shipped defaults. A route tester below the rules says which one would claim a URL.

Boarding

Asks at the

Browsers hide their install button in a menu nobody opens. PWA waits for the browser’s offer, then asks with your copy, after the delay you set.

Web push PRO

Push from your
own server

Craft signs and encrypts each notification itself and hands it to the browsers’ own push services. No third party, no per-message fee.

  • VAPID keypair generated for you, kept out of project config
  • Encrypted end to end to RFC 8291, tested byte for byte against its vector
  • Sent in batches on the queue, each delivery recorded per device
  • Dead endpoints dropped, and a broadcast on first publish if you want one
Saving and sending are separate steps. Sending is armed by typing SEND, because a notification cannot be recalled.
